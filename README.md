# 🌡️ IoT Temperature Monitor

A simple IoT system that simulates a temperature sensor in C and visualizes the data in real time using a web dashboard.

## 🚀 Features

* Temperature simulation in C
* Data sent via HTTP (POST requests)
* Python Flask backend
* Real-time chart using Chart.js

## 🧱 Architecture

Sensor (C) → HTTP → Flask → Web Dashboard

## ⚙️ How to Run

```bash
python app.py
./sensor.exe
```

Open:
http://127.0.0.1:5000
